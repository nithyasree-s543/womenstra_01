## 📌 The Problem
In rural India, **over 48% of rural women and girls have never used the internet**. Women are locked out of digital, financial, and government welfare ecosystems by interface design—not by lack of capability. Traditional apps require fluent reading, English comprehension, and complex multi-step navigation.

**Womentra** solves this from the ground up: a **voice-first, zero-literacy progressive web app (PWA)** that allows any woman to speak in her native tongue, learn high-income vocational skills, access government welfare schemes, connect 1:1 with verified mentors, and step into financial independence.

## 🌟 Key Features

### 1. 🗣️ Zero-Literacy Voice-First Experience
- **Auto-Narration (TTS):** Every screen, card, and action auto-narrates in the selected Indian language with an on-demand speaker replay button.
- **Floating AI Companion ("Womentra Didi"):** Persistent glowing microphone powered by Google Gemini that understands natural colloquial queries like *"Mujhe silai sikhna hai"* or *"Matru Vandana yojana ke baare me batao"* and auto-navigates.
- **Voice-Guided Onboarding:** The AI asks name, village, and goals via voice and auto-fills profile details.
- **Large Touch Targets:** Minimum 56px touch buttons, color-coded visual cards, and mascot guide.

### 2. 🏛️ "Sarkari Saathi" (Government Welfare Hub)
- **10+ Curated Central & State Schemes:** Pradhan Mantri Matru Vandana Yojana (PMMVY - ₹5,000 grant), Lakhpati Didi (SHG-NRLM micro-enterprise loans up to ₹5 Lakh), Sukanya Samriddhi Yojana (8.2% interest), PM Ujjwala 2.0 (free LPG), PM MUDRA loans, and Ayushman Bharat.
- **Voice Eligibility Checker:** Simple 2-question audio quiz to instantly determine eligibility.
- **Interactive CSC Locator (Leaflet Map):** Real-time GPS & geolocated Common Service Centers (Jan Seva Kendra) with operator names, verified badges, and phone numbers.
- **Step-by-Step Application Tracker:** Live tracking stages from submission to DBT bank transfer.

### 3. 🧵 "Hunar Hub" (Vocational & Digital Learning)
- **5 Multi-Module Voice Courses:**
  1. *Digital Money & UPI Scam Suraksha* (Never enter PIN to receive money, fake call prevention)
  2. *Village Tailoring to Boutique Mastery* (Body measurements, blouse & salwar pattern cutting, pricing)
  3. *Self-Help Group (SHG) & Bachat Shakti* (Group register books, bank linkage, revolving funds)
  4. *AI & Smartphone Tools for Rural Entrepreneurs* (Voice business posters, translation, calculations)
  5. *Daily Literacy & Practical Market Math* (Currency identification ₹10-₹500, signboards, medicine dates)
- **Interactive Audio Waveform Player:** Calm voice pace tailored for first-time learners.
- **Voice Quizzes:** Spoken questions with celebratory confetti animations and XP points.
- **Offline Download Cache:** One-tap save for low-bandwidth 2G/3G connectivity.

### 4. 🤝 1:1 Dedicated Mentorship & Child Protection
- **Dedicated Mentor Assignment:** Matched by language, state, and vocational goal.
- **Voice Notes & Audio Chat:** Send and receive voice notes without typing.
- **DigiLocker Verified Tutors (e-KYC):** Tutors undergo simulated DigiLocker token verification and certificate checks. Raw Aadhaar numbers are never stored (privacy-by-design).
- **Dependents & Child Linking:** Mothers can link daughters/sisters with separate learning profiles and linked tutors.
- **Guardian Minor Protection Banner:** Guardian observer controls during minor live calls.

### 5. 📹 Live Class Room & Video Tutoring
- **Low-Bandwidth Mode:** Instant switch between Video and Audio-only mode for rural 2G/3G networks.
- **Raise Hand by Voice:** Audio and visual notification for the tutor.
- **Live Hindi Subtitles:** Real-time caption banners for noisy environments.

### 6. 👭 "Sakhi Circle" (Community & Opportunities)
- Safe, moderated peer-to-peer audio space for women to share success stories and village job openings (SHG hiring, tailoring orders).
- Built-in one-tap content reporting in compliance with the **Digital Personal Data Protection (DPDP) Act 2023**.

### 7. 🌸 Confidence Builder & Badges
- Daily uplifting affirmations.
- Inspiring audio podcasts celebrating real rural trailblazers (e.g. Chhavi Rajawat, Kalpana Saroj).
- Verified downloadable Certificate of Achievement and gamified badges (*Pratham Kadam*, *Digital Nari*, *Bachat Sakhi*, *Hunar Didi*).

### 8. 🚨 Safety & Emergency Location Sharing
- One-touch emergency SOS alert with live coordinates sent to family and helpline.
- Privacy-controlled opt-in live journey location sharing on Leaflet map during CSC visits.

### 9. 💳 Transparent Packages & NGO Sponsor Codes
- **Saathi (Free):** Always 100% free for all rural learners.
- **Pragati (Monthly - ₹199):** Dedicated 1:1 verified mentor and live classes.
- **Shakti Pro (Annual - ₹1,499):** Complete business incubation and Mudra loan support.
- **Free NGO / Govt Sponsorship:** 1-click code redemption (`SAKHI2026`, `NRLM_FREE`) for subsidized access.
- **Razorpay Sandbox Integration:** Zero-friction test checkout simulation.

### 10. 🛡️ Admin Management & CMS
- Real-time impact metrics (Enrolled women, sanctioned grants, course completion).
- Tutor e-KYC approval queue.
- Scheme repository CMS.
- Mentor rating audit.

## 🛠️ Technology Stack

- **Frontend:** React 19, Vite, Tailwind CSS, Lucide Icons, Canvas Confetti, Leaflet & React-Leaflet
- **Backend:** Node.js, Express REST APIs, JWT, CORS, Multer
- **Database:** Modular File-backed SQLite/JSON Store with full seeds (PostgreSQL / Supabase compatible)
- **AI & NLP:** Google Gemini 1.5/2.0 API for voice dialogue, scheme eligibility parsing & text simplification
- **Voice Synthesis & Recognition:** Web Speech API (`SpeechSynthesis` & `webkitSpeechRecognition`) + Web Audio Chime Synthesizer
- **PWA Capabilities:** Standalone Web Manifest, Service Worker offline caching, responsive mobile-first UI
- **Payments:** Razorpay test sandbox simulation & API endpoints

## 🚀 Quick Setup & Installation

### Prerequisites
- **Node.js**: v18.0 or higher (`node -v`)
- **npm**: v9.0 or higher (`npm -v`)

### 1. Clone the repository
```bash
git clone https://github.com/nithyasree-s543/womenstra_01.git
cd womenstra_01
```

### 2. Install all dependencies
```bash
npm run install:all
```
*(Or install root, client, and server individually)*:
```bash
npm install
cd client && npm install
cd ../server && npm install
cd ..
```

### 3. Setup Environment Variables
Copy `.env.example` to `server/.env`:
```bash
cp .env.example server/.env
```
*(Optional: Add your Google Gemini API Key in `server/.env` to enable live Gemini AI queries. If omitted, Womentra's built-in rural conversational engine will seamlessly handle queries)*.

### 4. Run the Full-Stack Application
```bash
npm run dev
```
- **Frontend Client:** [http://localhost:3000](http://localhost:3000)
- **Backend REST API:** [http://localhost:5000/api/health](http://localhost:5000/api/health)
